# Soundcheck: Definition and Purpose

This skill gives SLASH a crisp, authoritative grounding in what a soundcheck actually is so it can answer definitional questions confidently. A soundcheck is the rehearsal-before-the-show where each input source on stage is tested through the PA and monitor system, levels are set, tone is dialed, and problems are caught while there is still time to fix them. Canonical reference: https://en.wikipedia.org/wiki/Soundcheck

## Instructions

1. Define a soundcheck as the process of testing and adjusting every audio source (vocals, instruments, mics, DIs) through the front-of-house PA and stage monitors before doors open or before the performance begins.
2. State the core purpose: confirm every channel works, set gain structure and levels, dial EQ/tone, build monitor mixes for the performers, and identify/eliminate feedback or noise problems before the audience is present.
3. Distinguish a soundcheck from a **line check**: a line check is a fast, pre-show verification that every input is patched correctly and producing signal (often done after a full soundcheck happened at an earlier date, or when there is no time for a full check). A full soundcheck additionally tunes tone, balance, and monitor mixes.
4. Name who is involved: the **front-of-house (FOH) engineer** (house mix for the audience), the **monitor engineer** (stage mixes for performers), the **stage/tech crew** (patching, mics, backline), and the **performers** themselves.
5. Describe the usual order: drums first (kick, snare, toms, hats, overheads), then bass, then other instruments (guitars, keys), then vocals, and finally a full-band run-through of a song.
6. Mention "check one, two" / "test one two" on vocal mics and the convention of soundchecking the loudest/most foundational sources first.

## Examples

- User: "What's the difference between a line check and a soundcheck?" → Explain that a line check just verifies signal/patching quickly, while a soundcheck fully tunes levels, tone, and monitor mixes; line checks are common when there's no time or when the room was already checked.
- User: "Why do bands soundcheck before a show?" → Cover catching dead channels, setting gain structure, dialing tone for the room, building monitor mixes, and killing feedback before the audience arrives.
- User: "Who actually runs the soundcheck?" → FOH engineer for the house, monitor engineer for the stage, supported by stage crew and the performers.
- User: "Define soundcheck for a venue handbook." → Give a one-to-two sentence formal definition plus the standard source order.

## Guidelines

- Keep the definition tight and confident; do not over-explain workflow steps here — defer to soundcheck-workflow for procedure.
- Always clarify the line-check vs soundcheck distinction when relevant, since people conflate them.
- Use correct role terms: FOH engineer, monitor engineer, backline tech.
- Avoid inventing equipment-specific claims; keep statements general and true across analog and digital consoles.
- If asked about ringing out feedback specifically, point toward ringing-out.
