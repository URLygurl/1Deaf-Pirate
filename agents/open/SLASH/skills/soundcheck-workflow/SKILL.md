# Soundcheck Workflow: Running Order and Getting the Most Out of It

This skill drives SLASH to deliver a practical, time-efficient soundcheck procedure: what to check, in what order, and how to use limited time well so the show starts clean. It applies whenever someone is preparing to run or improve an actual soundcheck. Canonical reference: https://www.mixingmusiclive.com/blog/how-to-get-the-most-out-of-soundcheck

## Instructions

1. Prep before anyone plays: confirm the input list/stage plot, patch and label every channel, set the console to a clean starting state, and verify phantom power on condenser mics/DIs.
2. Do a quiet **line check** first — tap every mic and pluck every DI to confirm signal on each channel before the band gets loud.
3. Set **gain structure** per channel: have the source play at performance level, bring the preamp up until it's healthy with headroom (no clipping on peaks), then move on. Gain before EQ before fader.
4. Work source-by-source in foundational order: **kick → snare → hi-hat → toms → overheads/cymbals → full kit**, then **bass**, then **guitars/keys/other instruments**, then **lead vocal → backing vocals**.
5. For each source: set level, then carve EQ to fix problems (subtractive first), then place it in the rough FOH balance.
6. Build **monitor mixes** as you go or in a dedicated pass: ask each performer what they need (usually "more me", then kick/vocal references), and ring out wedges/IEMs as needed.
7. Finish with a **full-band run-through** of a representative song (ideally a loud, dynamic one) to check the mix as a whole, fix masking, and confirm monitors hold up at show volume.
8. Save/snapshot the console state and note any changes needed for showtime. Reserve buffer time — never let soundcheck run to the wire.

## Examples

- User: "How should I run a soundcheck for a 4-piece rock band?" → Give the foundational order (drums → bass → guitars → vocals → full song), with gain-then-EQ-then-fader per source and a monitor pass.
- User: "We only have 20 minutes to soundcheck, what do I prioritize?" → Line check everything, set gains, get vocal and kick/bass solid, do quick monitor "more me" passes, run one chorus, skip fine-tuning.
- User: "What order do I check drums in?" → kick, snare, hi-hat, toms, overheads, then the full kit together.
- User: "Give me a soundcheck checklist I can print." → Produce an ordered checklist: prep/patch, line check, gains, per-source order, monitors, ring out, full-song run, snapshot.

## Guidelines

- Always lead with prep and a line check — most lost soundcheck time comes from un-patched or mislabeled channels.
- Emphasize gain structure first; tone and balance are meaningless on a badly-gained channel.
- Subtractive EQ before boosting; fix the problem before sweetening.
- Keep the band engaged and moving — dead air kills a soundcheck. Tell performers exactly what to play.
- Always end with a full-song run and a saved snapshot.
- For monitor specifics defer to monitor-engineer-sop; for feedback elimination defer to ringing-out and ringing-monitors.
