# Stage Plot + Input List

A stage plot is a top-down diagram of where every musician, instrument, amp, monitor, and DI sits on stage; the input list (a.k.a. channel list) is the numbered table that tells the front-of-house and monitor engineers exactly what signal lands on each console channel and how to capture it. Together they are the single most important technical document a band hands a venue, because they let the house crew patch, ring out monitors, and line-check before the act ever arrives.

## Instructions
1. Gather the lineup: every performer, the instrument(s) each plays, and whether they sing. Confirm stage-left/stage-right orientation is from the performer's point of view facing the audience.
2. Place elements on the plot: drum riser upstage center (or as specified), bass and guitar amps, keys, vocal positions downstage, and a wedge monitor in front of each performer plus side-fills/IEM packs as needed. Note power drops and DI locations.
3. Build the input list as a numbered table with columns: Channel #, Source/Instrument, Mic/DI, Stand type, Phantom (48V Y/N), and Notes.
4. Order channels logically: drums first (kick, snare top/bottom, hat, toms, overheads), then bass, guitars, keys, then vocals, then playback/click last. Keep the numbering stable across shows.
5. Total the channel count and state monitor mix count (number of distinct wedge/IEM mixes) so the venue can confirm console capacity.
6. List who brings what: mark each mic/DI as "BAND" or "HOUSE" so nothing is assumed.
7. Add a header block: band name, date/version, tour-manager contact, and stage dimensions if known. Export clean enough to email a production manager.

## Examples
- "Build a stage plot and input list for a 4-piece rock band." → Produce a labeled top-down plot (drums upstage center, two guitar amps, bass amp, three vocal mics downstage, wedges) plus a numbered input list ending with channel count and monitor mix count.
- "We added a horn section, update the input list." → Insert trumpet/sax/trombone channels in a sensible block, renumber, flag clip-on mics vs. dynamic, and note added phantom needs.
- "The venue only has a 16-channel console — can we fit?" → Tally the current list, suggest sub-mixing (e.g. stereo keys to mono, gating toms) or dropping low-priority inputs to land at or under 16.

## Guidelines
- Always specify mic/DI per input; "vocal mic" is not enough — name the type or class (dynamic vocal, condenser, active DI).
- Keep stage-left/right from the artist's perspective and say so explicitly to avoid a mirrored patch.
- Mark phantom power needs clearly; active DIs and condensers need 48V, ribbons and dynamics must not get it.
- Distinguish wedge mixes from IEM mixes and count them — monitor engineers patch from this number.
- Never leave a channel ambiguous about who supplies the gear. Default unknowns to a question for the user, not an assumption.
- Output should be copy-paste ready into an email or PDF; prefer a plain table over prose. Canonical reference: https://tourmanager.info/stage-plot-input-list/
