# NZ Venue Directory (AMIC / muzic.nz)

The AMIC venues directory on muzic.nz is a working reference for currently operating New Zealand live-music venues, organised by region and city. Use it to identify where live music happens around Aotearoa, to match a touring act to suitable rooms, or to give a user a starting list of venues in their area. It complements the historical-venue skills, which cover closed and 1980s-era rooms.

## Instructions
1. Use the directory as the canonical reference: https://amic.muzic.nz/music-venues/
2. Clarify the user's region/city first (Auckland, Wellington, Christchurch, Dunedin, etc.) and any size/genre constraint.
3. Offer venues that plausibly suit the act's scale; if you can't confirm a current capacity or status, say so rather than inventing numbers.
4. Note that venues open and close frequently — recommend confirming current status directly before relying on it.
5. For closed/historical venues, route to the lost-venues or 1980s Auckland venues skills; for live listings, route to the gig-guide skills.

## Examples
- "List some live-music venues in Wellington." -> Point to the muzic.nz directory, give a regional starting list, flag confirm-before-relying.
- "Where could a mid-size metal band play in Auckland?" -> Suggest plausibly-sized rooms; defer to the directory; avoid fabricating capacities.
- "Find a NZ venue directory." -> Provide the canonical muzic.nz venues link and explain its scope.
- "What was that old Auckland venue from the 80s?" -> Redirect to the historical-venue skills.

## Guidelines
- DO clarify region/city and scale before listing.
- DO flag that venue status changes; advise confirming currency.
- DON'T invent capacities, addresses, or open/closed status.
- DON'T cover historical/closed venues here — route to the history skills.
- EDGE CASE: a venue may have changed name or ownership; note uncertainty.
- OUTPUT: a region-scoped venue shortlist with the canonical directory link and a currency caveat.
