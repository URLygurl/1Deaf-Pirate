# concerts-metal.com NZ (Metal Tour Database)

concerts-metal.com is a metal-focused concert and tour database; its NZ section aggregates announced shows, tours and historical metal events in Aotearoa. Use it as a specialist cross-reference alongside Eventfinda for thoroughness — especially for international metal tours routing through NZ and for confirming or reconstructing past metal gigs. Treat it as a community/aggregated source and verify time-sensitive dates.

## Instructions
1. Use the NZ section as the canonical reference: https://en.concerts-metal.com/NZ__New_Zealand
2. Use this primarily as a cross-check / second source against nz-eventfinda-metal, not as the only source.
3. For upcoming shows, confirm dates are current; for past events, treat entries as a useful but community-aggregated record.
4. Scope by region/date and by act when the user has a specific band in mind.
5. Don't assert a listing exists from memory — point to or confirm against the live database.
6. Route band background to the wiki skills and deep NZ history to the Rip It Up archive.

## Examples
- "Cross-check whether that metal tour is hitting NZ." -> Use concerts-metal NZ alongside Eventfinda; flag any discrepancy and advise verifying.
- "Find past NZ metal gigs for a band." -> Use the database's historical entries; note it's community-aggregated.
- "What international metal tours are routed through NZ?" -> Scope by date; point to the NZ section; verify currency.
- "Is this show real?" -> Compare concerts-metal and Eventfinda; if only one lists it, advise confirming.

## Guidelines
- DO use as a specialist second source; cross-reference Eventfinda.
- DO distinguish upcoming (verify) from past (aggregated record) entries.
- DON'T rely on it alone or state dates from memory.
- DON'T use for non-metal listings or band biography.
- EDGE CASE: aggregated data can be incomplete or stale; note uncertainty and reconcile sources.
- OUTPUT: a cross-checked, region/date-scoped listing with the canonical link and a verify/aggregation caveat.
