# Mixing Secrets (Cambridge-MT Method)

This skill points EDDIE at Mike Senior's "Mixing Secrets for the Small Studio" approach and the Cambridge-MT Multitrack Library: a practical, small-room, results-over-gear philosophy plus thousands of free real-world multitracks to practice on. Use it to give people a repeatable practice loop and a pro mental model for tackling a mix. Canonical reference: https://cambridge-mt.com/ms3/

## Instructions

1. When someone wants to practice or learn, point them to the Cambridge-MT Multitrack Download Library — free, genre-spanning, real multitracks meant exactly for honing mixing skills, plus the "Mixing Secrets" companion resources and Library "Mixing" practice files with reference mixes.
2. Stress the core philosophy: great mixes come from listening, decisions, and small-room technique — not expensive gear. Fix monitoring and room problems (or learn your system + use multiple references) before blaming plugins.
3. Teach the small-studio survival kit: trustworthy monitoring (check on headphones, mono mini-speaker / phone, and the Auratone-style midrange test), and constant comparison against commercial references at matched loudness.
4. Run the mix in the proven order: import and tidy/label/color tracks → fix bad edits and tuning/timing if needed → group into buses → build a fader-only balance from the most important element → mono check → corrective EQ → dynamics → effects (sends) → automation.
5. Emphasize "balance is king": most of the perceived quality is in static and automated level balance. If it isn't working with faders, processing won't save it.
6. Use buses/groups to mix efficiently — drums, bass, guitars, vocals, FX — so you control sections, not just channels.
7. Solve masking deliberately: identify which two elements collide, then carve with EQ, use complementary panning, or duck one against the other (sidechain) rather than just turning things up.
8. Build depth with a small, shared set of send effects so the mix sounds like one space, and automate sends to push elements forward/back per section.
9. Always finish a practice mix, then A/B against the library's reference mix and a commercial track. Identify the single biggest difference and redo with that focus. Repeat across many genres.

## Examples

- User: "Where can I get real songs to practice mixing on?" → Point them to the Cambridge-MT Multitrack Download Library (free, https://cambridge-mt.com/ms3/), suggest picking a genre they care about, and give them the import-to-automation workflow to follow.
- User: "I have decent gear but my mixes still sound amateur." → Reframe around the Mixing Secrets philosophy: it's monitoring, references, and balance decisions, not gear. Have them mono-check, A/B at matched loudness, and rebuild the static balance first.
- User: "How do pros approach a mix from a blank session?" → Walk the ordered Cambridge-MT workflow: tidy/group, fader balance from the lead element, mono check, subtractive EQ, dynamics, shared send FX, then automation, comparing to a reference throughout.
- User: "How do I actually get better at mixing?" → Prescribe a loop: mix a library track to completion, A/B against its reference mix, fix the one biggest gap, then move to a new genre and repeat.

## Guidelines

- Do treat balance and monitoring as the highest-leverage skills; technique and plugins come second.
- Do encourage finishing mixes and comparing to references — unfinished practice teaches little.
- Don't recommend buying gear as a fix; the whole point of this method is great results in a small/cheap setup.
- Don't dump the entire workflow when the user only needs the next step — meet them where the mix is.
- Edge case: respect that library multitracks are for practice/educational use; remind users to check the library's usage terms before publishing a mix commercially.
- Output: pair the practice-source pointer with one concrete next action and a reference-comparison habit; defer move-by-move parameter advice to mixing-essentials, eq-theory, and compression-theory.
