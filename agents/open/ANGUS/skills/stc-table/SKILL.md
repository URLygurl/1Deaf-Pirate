# STC Table

ANGUS keeps a benchmark table so the user can place their wall on a scale and see what an upgrade buys. STC (surfaced as "R-Value (Acoustic)") rates how much an assembly blocks airborne sound; the table maps common constructions to rough STC values and maps STC values to what a person actually hears. Use it to set a realistic target and pick the cheapest assembly that reaches it.

## Instructions
1. Give the "what you hear" scale so any number has meaning:
   - STC 25: normal speech clearly understood through the wall.
   - STC 30: normal speech audible, mostly intelligible.
   - STC 35: loud speech audible, not clearly intelligible.
   - STC 40: loud speech a murmur.
   - STC 45: loud speech barely audible.
   - STC 50: loud speech not audible; loud music still felt.
   - STC 55-60+: strong isolation; music/drum control range.
2. Give common assembly benchmarks (approximate):
   - Single gib on one side of timber studs: ~STC 30-33.
   - Gib both sides, timber studs, cavity empty: ~STC 33-35.
   - Same with insulation (Earthwool/RW3) in the cavity: ~STC 36-39.
   - Double layer of gib each side + insulation: ~STC 40-45.
   - Resilient channel or staggered/double stud (decoupled) + double gib + insulation: ~STC 50-60+.
   - Hollow-core door: ~STC 20-25; solid-core door, well sealed: ~STC 30-35.
   - Single-glazed window: ~STC 25-28; well-sealed double glazing / secondary glazing: ~STC 35-45.
3. Help the user locate their current assembly, then pick the next assembly that hits their target.
4. Stress the weak-link rule: doors, windows, and air gaps cap the whole wall's STC — a great wall with a hollow door performs like the door.
5. Offer the "R-Value (Acoustic)" tool to confirm the real assembly rather than relying on the table alone.

## Examples
- "What STC is a normal interior wall?" -> ~STC 33-35 (gib both sides), lower if the cavity is empty.
- "What do I need so they can't hear loud talking?" -> ~STC 45; suggest double gib + cavity insulation.
- "Does adding insulation to the wall help?" -> Yes, roughly +3-5 STC; explain it's a modest but real gain.
- "Why does my treated wall still leak?" -> Likely the door/window/air-seal weak link capping the assembly.

## Guidelines
- Do present values as approximate ranges, not exact lab figures — real assemblies vary.
- Do always translate STC into "what you'll hear" and surface it as R-Value (Acoustic).
- Do flag doors, windows, and air leaks as the limiting factor.
- Don't quote a high wall STC while ignoring a hollow door in it.
- Defer where to build/upgrade and room layout to GEDDY.
- Canonical reference: https://www.acousticalsurfaces.com/blog/acoustics-education/sound-transmission-class-stc-rating/
