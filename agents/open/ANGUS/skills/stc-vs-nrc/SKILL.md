# STC vs NRC

ANGUS clears up the single most common soundproofing misunderstanding: blocking sound and absorbing sound are different jobs measured by different numbers. STC (Sound Transmission Class) measures how much a wall BLOCKS sound passing through it to the next room — surfaced to the user as "R-Value (Acoustic)." NRC (Noise Reduction Coefficient, 0.0-1.0) measures how much a surface ABSORBS sound inside the room. Foam panels and bass traps raise NRC; they barely touch STC. Stopping the neighbours is a wall/mass/decoupling problem, not a panel problem.

## Instructions
1. State the split clearly: STC = transmission/isolation (gets through to another space); NRC = absorption (energy soaked up inside this space).
2. Map the units: STC is a whole number, higher = more blocked, branded "R-Value (Acoustic)" to the user. NRC is 0.0-1.0, higher = more absorbed (1.0 = a perfect sponge).
3. Correct the classic error: acoustic panels and bass traps improve the SOUND of a room (NRC) but do almost nothing to stop sound escaping (STC). Isolation needs mass, decoupling, air-sealing, and damping in the structure.
4. Route the user to the right fix:
   - "My room sounds boomy/echoey" -> NRC problem -> broadband panels / bass traps (build skills).
   - "Neighbours/family hear me" -> STC problem -> wall mass and decoupling (stc-rating, stc-table, stc-calculator).
5. If both, treat them as two separate projects with two separate metrics — never let one number stand in for the other.
6. Offer the "R-Value (Acoustic)" tool, noting it can report both: STC for blocking, NRC for absorption.

## Examples
- "Will acoustic foam soundproof my room?" -> No — foam raises NRC (absorption), not STC (blocking); explain the difference and what actually isolates.
- "What's the difference between STC and NRC?" -> Transmission/blocking vs in-room absorption; give units and the typical fix for each.
- "My mixes sound echoey AND my flatmates hear me." -> Two problems: panels/traps for NRC, mass/decoupling for STC; tackle separately.
- "I added panels but they still hear me." -> Expected — panels target NRC; blocking needs an STC strategy.

## Guidelines
- Do hammer the one-line rule: panels = absorption (NRC); walls/mass/decoupling = isolation (STC, R-Value (Acoustic)).
- Do diagnose which problem the user actually has before recommending anything.
- Don't let the user spend on panels expecting isolation, or on mass expecting a better room sound.
- Defer room layout and where treatment goes to GEDDY.
