The Peach — Component Demo

AGENT ENABLED READ-ONLY TRIAL

Drop-in owner controls for any PeachyWeb app

The Peach is a self-contained component — one script block, zero dependencies. Any PeachyWeb app mounts it with a single call: PeachyWeb.mount(config). The app logs events with PeachyWeb.log(...). Everything else — the floating button, the slide-up panel, BroadcastChannel sync with the Ops Center — is handled inside the component.

The component is deliberately absent from the agent's manifest. No open_settings. No set_policy. No peach.* namespace. The control plane lives outside the data plane — by design, not by ACL.
