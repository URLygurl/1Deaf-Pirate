# The Company Brain — Operating Map

> Memory is raw material. Retrieval is the operating layer.

Scattered company context (Slack, calls, HubSpot, SOPs, sales notes, decisions, logs) is signal
from everywhere. Disconnected context is lost context. The brain turns it into an operating edge.

## The flow (mirrors `hive/`)
1. **Capture** — record the work; raw material enters the system. *Storage, not intelligence.*
2. **Retrieval** — right context now; reduce human re-explaining.
3. **Source Truth** — what's true now; without it, agents stay confident liars.
4. **Permissions** — who sees/does what; one big brain with no walls is dangerous.
5. **Feedback loops** — every correction strengthens the system; repeated mistakes disappear.
6. **Execution** — work gets done with context, proof, fewer cycles.

## Broken model vs working model
- **Broken:** prompt → output → scattered feedback → lost decision → restart (agent starts cold).
- **Working:** calls/CRM/SOPs → retrieval (right context) → agent → work (artifacts) → correction (review) → rule (next time it's better).

## Principles that keep the brain strong
One source of truth · decisions are logged · context is curated · access is controlled ·
feedback compounds · memory is a competitive edge.

## Workflow audit — 6 questions before automating
1. What sources does this workflow need?
2. Which source wins when they conflict?
3. What context is always required?
4. What context should never be used?
5. What corrections repeat?
6. How does one correction become a rule?
