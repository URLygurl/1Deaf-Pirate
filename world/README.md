# World Build — DefPirate / Deadsound

The fully fleshed-out world the agents live in. The skin is real: rock legends, a pirate crew,
a shared sound.

| Folder | Holds |
|---|---|
| `lore/` | WORLD-LORE — the canon. Who the crew is, the Deadsound story, how DefPirate came to be. |
| `personas/` | The rock-legend avatars — one file per persona (bridges to each agent's SOUL.md). |
| `brand/` | Visual identity. DefPirate green `#7EFF00`. See `brand/palette.md`. |
| `voice/` | Tone & copy — greeting scripts (NEIL says hi for Coryt), the crew's way of speaking. |

> The world build is what makes the swarm *feel* like a crew instead of a tool. Reveal is slow
> and staged — DIME + NEIL first.
