Shared Memory Store
One persistent key-value brain every agent reads and writes to. A single shared namespace. GIGGUIDE writes a venue insight → immediately queryable by all 14 others including Neil. No sync delay. No polling. What one knows, they all know.

Agentic Event Bus
Every memory write publishes a typed event. Every agent subscribes to categories relevant to their role. Neil subscribes to anything that affects the public-facing response — show changes, booking status, campaign embargoes, issue resolutions. Fully agentic.
