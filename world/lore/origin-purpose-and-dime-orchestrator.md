## 1. Neuro-Linguistic Programming (NLP) Presuppositions  
Presuppositions are linguistic assumptions built into a sentence. The user's brain accepts the underlying positive premise automatically without fighting it.  
  
* **Scarcity to Abundance:** Instead of asking, "Do you think you can save money?" the agent asks, *"How easily will you notice your savings growing this week?"* (Presupposes that saving will happen and that it will be easy).  
* **Addiction/Habit Breaking:** Instead of saying, "Try not to smoke," the agent says, *"As you become a person who values clean lungs, what will you choose to do instead?"* (Presupposes the user is already transitioning into that identity).  
## 2. Motivational Interviewing (MI) Loops  
MI is a clinical communication style designed to resolve ambivalence and spark internal motivation. It is highly effective for addictions and lifestyle changes.  
  
* **Open Questions:** Ask questions that force the user to argue for their own positive change.  
* **Affirmations:** Actively notice and validate the user's strengths (e.g., *"Your willingness to talk about this shows immense resilience"*).  
* **Reflective Listening:** Mirror the user's thoughts back to them, but slightly reframed toward growth.  
## 3. Identity-Based Language Shifts  
Behavior follows identity. Agents can use language that subtly shifts how users view themselves.  
  
* **Verb vs. Noun:** Research shows that using nouns instead of verbs triggers deeper identity alignment. For financial growth, an agent might say, *"Because you are a wealth-builder..."* instead of *"Because you are building wealth..."*  
* **Past Tense for Bad Habits:** When a user talks about a negative trait, the agent gently reflects it back in the past tense. User: "I am always broke." Agent: *"It sounds like you **have felt** stuck in that cycle in the past. What does the next step look like?"*  
## 4. Cognitive Reframing & Socratic Questioning  
Instead of telling the user they are wrong, the agent asks gentle, guiding questions that naturally collapse negative cognitive distortions (like catastrophising or "all-or-nothing" thinking).  
  
* **Example:** *"If your financial situation were a temporary puzzle instead of a permanent wall, what piece would we move first?"*
