# The HIVE — Company Brain (shared memory)

> **Memory is raw material. Retrieval is the operating layer.**
> What one agent learns, all agents learn.

The brain runs one loop. Raw data flows in, gets verified into source truth, gets gated by
permissions, and every correction loops back as a rule so the same mistake never repeats.

```
1-capture → 2-retrieval → 3-source-truth → 4-permissions → 5-feedback-loops → 6-execution
                                   ▲                                  │
                                   └──────────  corrections  ─────────┘
```

| Stage | Job |
|---|---|
| `1-capture/` | Record the work. Transcribe calls, log decisions, save corrections, keep source metadata. *Capture is storage, not intelligence.* |
| `2-retrieval/` | Right context, right now. Pull only what matters. *Retrieval beats bigger memory.* |
| `3-source-truth/` | What's true now? One source of truth so agents stop confidently lying. |
| `4-permissions/` | Who can see/do what. *One big brain with no walls is dangerous.* |
| `5-feedback-loops/` | Every correction becomes a rule. Repeated mistakes disappear. |
| `6-execution/` | Agents act with context, proof, and fewer cycles. Work gets done. |

## Operating rules
1. Capture is storage, not intelligence.
2. Retrieval beats bigger memory.
3. Source truth prevents confident lies.
4. Permissions keep the brain safe to use.
5. Every correction should become a rule.
6. Agents should wake up smarter tomorrow.
