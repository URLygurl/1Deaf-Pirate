# The Groove Plan

The 16-week finishing plan for this platform, as a design canvas. Five artboards:

| File | Board |
|---|---|
| `Main.dc.html` | The one move — the thesis and the first thing to do |
| `Reality.dc.html` | The ledger — every piece of both repos, its state, the evidence |
| `Plan.dc.html` | The plan — four phases, each with a finish line and a not-doing list |
| `Loop.dc.html` | The weekly bar — the rhythm, drawn as a step sequencer |
| `Rules.dc.html` | Six rules that hold the line |
| `canvas.json` | Layout: where each board sits on the canvas |

Brand is `world/brand/palette.md` — DefPirate green `#7EFF00` on near-black,
Archivo Black over IBM Plex Mono.

## Editing

These `.dc.html` files are the source. The published canvas is rebuilt from
them — edit here, then re-seed and republish. `groove-plan.html` is build
output (~2 MB of editor payload) and is gitignored.

Ask Claude Code to re-seed and update the canvas; it re-runs the `/design`
helper against these files and republishes to the same link.
